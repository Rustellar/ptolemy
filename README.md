<h1 align="center">
    <p>Ptolemy</p>
</h1>

---

[> Important]Ptolemy は、Rustellar が作成したプロジェクトで殆ど使用されているライブラリです。このプロジェクトは、頻繁な変更が加えられる可能性があります。

---

Ptolemy は以下の機能を提供する便利なライブラリ群です。

- UTF-8 以外でエンコードされたファイルを、指定したエンコードで読み込んで `Vec<String>` で返す `formatter.rs`
- `<ruby>漢字<rt>よみかた</rt></ruby>` で記述されたルビを、 `[漢字](かんじ)` に変換して `String` で返す `converter.rs`
